# SPHEREx Blink

NASA Space Apps Challenge 2026, challenge "Planet X and SPHEREx": a public web tool that shows a time-lapse of SPHEREx sky images for any RA/Dec.

Status: scaffold. See `docs/problem-solution.md`, `docs/backlog.md`, `shared/openapi-contract.json`.

- Backend: `cd backend && cargo test`
- Frontend: `cd frontend && npm install && npm run dev`
